# Computational Verification

This repository contains three Python scripts for reproducing and verifying computational results presented in our paper.

## File Descriptions

1. **`Example 7_compute_dT.py`**  
   Computes the minimum toroidal distance of the code constructed in Example 7.

2. **`Example 7_Delsarte LP Bound.py`**  
   Computes the Delsarte linear programming (LP) upper bound for Example 7 with parameters \(n=16\), \(q=4\), and \(M=65536\).

3. **`ref[3] Table compute dT .py`**  
   Computes the minimum toroidal distance of the length-16 code reported in Table 1 of the following reference:

   C. Bachoc, T. A. Gulliver, and M. Harada, "Isodual codes over Z₂ₖ and isodual lattices," *Journal of Algebraic Combinatorics*, vol. 12, no. 3, pp. 223–240, 2000.
